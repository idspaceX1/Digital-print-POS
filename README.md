# 📇 Digital-Print-POS

A **web-based Point of Sale (POS)** system tailored for **digital print shops**, designed to manage sales, inventory, employees, and printing orders in one intuitive interface.

> This project provides a foundational POS system built with plain JavaScript, aiming to simplify retail operations in digital print businesses.

---

## 🚀 Features

✔️ Dashboard overview – quick insights into sales & orders
✔️ Cashier module – fast transaction processing
✔️ Inventory management – track print materials & products
✔️ Employee management – add/edit staff information
✔️ Design & print orders – handle custom print requests
✔️ Setup & configuration – initial system settings

---

## 📁 Project Structure

| File              | Description                    |
| ----------------- | ------------------------------ |
| `dashboard.js`    | Dashboard logic and UI         |
| `cashier.js`      | POS transaction handling       |
| `inventory.js`    | Inventory and stock management |
| `employee.js`     | Employee data handling         |
| `design-print.js` | Custom design & print workflow |
| `setup.js`        | Application configuration      |
| `*.json`          | Data or configuration storage  |
| `LICENSE`         | MIT License                    |

---

## 🧠 How It Works

Each module is separated by responsibility, making the system easy to understand, modify, and extend.
The application is designed to be lightweight and adaptable for small to medium digital printing businesses.

---

## 💡 Getting Started

### Clone the repository

```bash
git clone https://github.com/idspaceX1/Digital-print-POS.git
cd Digital-print-POS
```

### Run the project

* Open the main HTML file in a browser (if available), or
* Serve it locally:

```bash
npx http-server .
```
